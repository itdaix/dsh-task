# dsh-task · 定时任务插件

给 DSH 加一个「定时任务」功能：按 CRON 表达式定时，把一句话自动发到指定的会话里，跑完记一笔日志。
<img width="978" height="486" alt="image" src="https://github.com/user-attachments/assets/3ccc760d-79cd-4d08-b2c8-a780a818bfd4" />




## 能干什么

- 随 DSH 一起启动，全局生效。
- 设置面板里多一个「定时任务」页，卡片式管理多个任务。
- 每个任务：到点自动往指定会话发提示词，等同你亲手打字。
- 每次跑完写日志（时间 / 成功失败 / 耗时 / AI 回复），可在页面里查看。
- 支持 OVERLAP（执行中又到点怎么办）：`skip` / `allow` / `queue`。

## 怎么实现的（大白话）

插件拆成两半：

| 半身 | 干什么 |
|---|---|
| 后台（Host） | 随 DSH 启动，驻在进程里盯时间 |
| 界面（Client） | 设置页里的「定时任务」卡片页 |

核心就四件事：

1. **定时**：一个每秒醒一次的「闹钟」，瞄一眼当前时间，比对 CRON 该不该触发（命中才动）。
2. **发消息**：不自己造轮子，喊 DSH 官方接口「帮我把这句话发到这个会话」，效果等于你亲手打字，AI 照常回答。
3. **记日志**：每跑完一次，往 `.log\当天日期.jsonl` 追加一行（时间、状态、耗时、提示词、AI 回复）。
4. **存配置**：任务列表存在插件的 `config.json`，界面点保存后后台立刻重排闹钟（不用重启）。

## 任务字段

| 字段 | 说明 |
|---|---|
| 任务编号 | 自动生成（UUID），不用管 |
| 任务描述 | 一句话，显示在卡片上 |
| 指定 SESSION | 下拉选一个已有会话（显示「工作区名 - 会话描述」）|
| 提示词 | 到点发给 AI 的那句话 |
| CRON | 触发时间表达式 |
| OVERLAP | 执行中又到点：`skip`（跳过）/ `allow`（并发）/ `queue`（排队）|
| 启用 | 开关 |

## CRON 表达式怎么写

支持两种段数：

| 段数 | 格式 | 最小粒度 | 说明 |
|---|---|---|---|
| 5 段 | `分 时 日 月 周` | 分钟 | 日常定时用这个 |
| 6 段 | `秒 分 时 日 月 周` | 秒 | 要「每 N 秒」才用 |

### 各字段范围

| 字段 | 范围 |
|---|---|
| 秒 | 0–59（仅 6 段）|
| 分 | 0–59 |
| 时 | 0–23 |
| 日 | 1–31 |
| 月 | 1–12（或 JAN–DEC）|
| 周 | 0–7（0 和 7 都是周日；或 SUN–SAT）|

### 符号

| 符号 | 含义 | 例子 |
|---|---|---|
| `*` | 每个值 | `* * * * *` 每分钟 |
| `5` | 恰好那个值 | `30 8 * * *` 每天 8:30 |
| `*/n` | 每 n 个（步长）| `*/30 * * * *` 每 30 分钟 |
| `a-b` | 范围 | `9-17 * * * *` 9 点到 17 点每小时 |
| `a,b` | 列表 | `0,30 * * * *` 第 0 和 30 分 |
| `a-b/n` | 范围内每 n | `0-30/10 * * * *` 0、10、20、30 分 |

### 常见例子

| 想干什么 | 写法 |
|---|---|
| 每天 8:30 | `30 8 * * *` |
| 每小时整点 | `0 * * * *` |
| 每 30 分钟 | `*/30 * * * *` |
| 工作日 9:00（周一至周五）| `0 9 * * 1-5` |
| 每 30 秒（测试用）| `*/30 * * * * *` |
| 每 10 秒 | `*/10 * * * * *` |

> 注意：5 段最小到「分钟」，做不到「每 N 秒」；要秒级必须用 6 段，最前面多一个「秒」。

## 安装

link 装进全局 web profile：

```powershell
node C:\deepseek-harness\apps\cli\lib\bin.js plugin --profile web add E:\03_智能体\dsh-plugins\dsh-task
```

装完重启 DSH，设置面板里就会出现「定时任务」。

## 日志

位置：`E:\03_智能体\dsh-plugins\dsh-task\.log\<日期>.jsonl`（一天一个文件，追加写）。页面里点任务的「日志」按钮即可按时间倒序查看。
